Migration traffic mapper

Load an Azure Migrate dependency export or netstat output. See which servers talk to each other, which flows break when you split servers across migration waves, and get NSG and Azure Firewall rules for the target network.

Azure Migrate export, CSV or netstatRuns in your browserNo data leaves your machine

STEP 1Load connection data An example is loaded so you can see the output

In Azure Migrate, open Dependency analysis → Export application dependencies, unzip the file and choose the CSV. Columns used: Source server name, Source process, Destination server name, Destination IP, Destination process, Destination port.

Paste rows with a header line. Recognised columns: source, source_ip, destination, destination_ip, port, protocol. Names or IPs both work.

On each server run netstat -ano (Windows) or ss -tan / netstat -tan (Linux), paste the output and add it. Repeat for each server; flows are merged.

STEP 2Map servers to waves and target subnets Edit any cell; results update instantly

Set the migration wave for each server, or mark it as staying on-premises. Add the target subnet CIDR in Azure to generate rules with Azure address ranges.
